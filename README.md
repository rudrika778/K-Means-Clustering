# Customer Segmentation using K-Means Clustering

## What does this project do?
This project groups 60 customers based on their annual income and 
spending score to identify customer behaviour patterns and find 
the most valuable customers for a business.

## Features used
- Annual Income (in $1000s)
- Spending Score

## Libraries used
- NumPy
- Matplotlib
- Scikit-learn

## How it works
1. Used the Elbow Method to find the best number of clusters
2. Applied K-Means Clustering to group customers
3. Extracted cluster centroids to understand each group
4. Visualized the clusters and centroids on a scatter plot

## How to run
1. Install libraries:
   2. Run `customer_segmentation.py`

## Key Concepts Covered
- Unsupervised Learning
- K-Means Clustering
- Inertia
- Elbow Method
- Cluster Centroids
